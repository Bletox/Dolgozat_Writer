### Feladat leírása
A feladat egy `Writable` interfész megvalósítása egy `Writer` nevű osztállyal, amely a kapott szöveget egy fájlba írja ki.

## Projekt struktúra
* `src/Writable.java` - A kért interfész a `writeContent` metódussal.
* `src/Writer.java` - Az interfészt megvalósító (implementáló) osztály.
* `src/App.java` - A főprogram, amely teszteli a fájlba írást.
* `kiíratás.txt` - A generált kimeneti fájl.
